## 0.1.0

- Initial release of MergeFlow.
- Three-pane merge conflict resolution experience.
- Yours, Result, and Theirs views.
- Editable Result pane.
- Conflict navigation and resolution actions:
  - accept, ignore and append changes from either side
  - Accept Both
  - Revert Conflict Resolution
  - resolve simple conflicts
- Apply non-conflicting changes from one or both sides.
- Merge Conflicts view with per-file progress.
- Abort Merge.
- Compare any two versions (Base, Yours, Theirs, Result) in VS Code's diff editor.
- Complete merge workflow: writes the Result and stages the file without committing. Also Accept Left / Accept Right for the whole file, and Cancel.
